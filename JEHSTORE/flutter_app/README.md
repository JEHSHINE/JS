# JEH Store Flutter App

This Flutter module is a mobile shell for the JEH Store customer app.

## Getting started

1. Navigate to `flutter_app/`.
2. Run `flutter pub get`.
3. Run the app with `flutter run`.

## Included features

- Login screen
- Home product browsing
- Cart screen placeholder
- API client service
